# Destaques do Instagram — Dias de Moda

3 destaques (bolinhas fixadas no perfil), cada um com **stories** para postar + **capa**.

## Como usar
1. Poste as stories de cada pasta (em sequência) no seu Instagram.
2. Ao salvar, crie/adicione no **Destaque** correspondente.
3. Defina a **capa** do destaque usando o `capa-*.png` correspondente.

## Estrutura

| Destaque | Capa | Stories |
|---|---|---|
| **Sobre** (quem somos) | `capa-sobre.png` | `sobre/s1.png` → `s4.png` |
| **Modelos** (tipos de uniforme) | `capa-modelos.png` | `modelos/m1.png` → `m4.png` |
| **Pedir** (como pedir) | `capa-pedir.png` | `pedir/p1.png` → `p4.png` |

## Detalhe de cada um

- **Sobre:** 36 anos de costura · uniformes que vestem a sua marca · Rio Verde · todo Goiás.
- **Modelos:** empresarial e equipes · saúde, estética e cozinha · escolas e eventos.
- **Pedir:** 1. envie a logo → 2. orçamento no mesmo dia → 3. produção → 4. entrega. CTA WhatsApp (+55 64 9943-1610).

Todas as artes em 1080×1920. Para regenerar: `node render-destaques.mjs` (a partir de `instagram/`).
