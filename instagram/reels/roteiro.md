## 🎬 Como montar (2 minutos)
1. Abra o **CapCut** (ou InShot) → novo projeto → importe os PNGs na ordem.
2. Ajuste cada imagem para **3s** (a última para 4s).
3. Adicione uma **música** suave (tendências de "negócios/loja").
4. Exporte em **1080×1920** e publique como Reel (fixe no perfil).
