## 🎯 Fluxo Recomendado

```
1. Abrir folheto-6up.html ou cartao-duplex.html
2. Ctrl + P (imprimir)
3. Ativar "Cores de fundo"
4. Imprimir (ou Salvar como PDF)
5. Cortar (no caso do folheto)
```

## ✅ Checklist de Impressão

- [ ] Arquivo correto aberto (6-up ou duplex)
- [ ] Chrome ou Edge
- [ ] Cores de fundo ATIVADAS
- [ ] Margens em "Nenhuma"
- [ ] Escala em 100%
- [ ] Papel correto (A4 para folheto)
