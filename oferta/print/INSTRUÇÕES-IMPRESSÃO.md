# 📄 Instruções para Impressão

## 📌 FOLHETO (6 por folha A4)

**Arquivo:** `folheto-6up.html`

### Como imprimir:
1. Abra o arquivo `folheto-6up.html` no navegador (Chrome ou Edge)
2. Aperte **Ctrl + P** (ou Cmd + P no Mac) para imprimir
3. Configure assim:
   - **Páginas:** Todas (serão 2 páginas)
   - **Layout:** Retrato
   - **Margensยน** Nenhuma
   - **Cores de fundo:** ✅ **MARCAR** (muito importante!)
   - **Escala:** 100%
   - **Papel:** A4

4. **Frente e Verso:**
   - **Página 1** = FRENTE com 6 folhetos
   - **Página 2** = VERSO com 6 folhetos
   
5. Para imprimir frente e verso:
   - Primeira impressão: só página 1
   - Vire a folha
   - Segunda impressão: só página 2

6. Depois é só cortar os 6 folhetos!

---

## 🎴 CARTÃO (frente e verso)

**Arquivo:** `cartao-duplex.html`

### Como imprimir:
1. Abra o arquivo `cartao-duplex.html` no navegador
2. Aperte **Ctrl + P** para imprimir
3. Configure assim:
   - **Páginas:** Todas (serão 2 páginas)
   - **Layout:** Paisagem
   - **Margens:** Nenhuma
   - **Cores de fundo:** ✅ **MARCAR**
   - **Escala:** 100%
   - **Papel:** 85mm × 55mm (ou use A4 e corte depois)

4. **Frente e Verso:**
   - **Página 1** = FRENTE
   - **Página 2** = VERSO

5. Imprima frente, vire o papel, imprima verso

---

## 💡 Dica para quem vai imprimir em gráfica

Se preferir levar para uma gráfica:
1. No navegador, ao invés de imprimir, escolha **"Salvar como PDF"**
2. Use as mesmas configurações acima
3. Leve o PDF para a gráfica

---

## ✅ Checklist antes de imprimir

- [ ] Cores de fundo estão MARCADAS
- [ ] Margens estão em NENHUMA ou 0
- [ ] Escala está em 100%
- [ ] O QR code aparece bem nítido na prévia
