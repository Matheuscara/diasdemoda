## 📝 Como sua mãe vai usar

### OPÇÃO 1: Imprimir em casa/escritório

```
1. Abrir o arquivo .html (clique duplo)
2. Ctrl + P
3. MARCAR "Cores de fundo" ⚠️
4. Imprimir
```

### OPÇÃO 2: Levar para gráfica

```
1. Abrir o arquivo .html
```

## 🎨 Como funciona o folheto 6-up

```
Folha A4 impressa:

┌──────────────────────────────────┐
│         │         │         │
│ Folheto │ Folheto │ Folheto │
│    1    │    2    │    3    │
│         │         │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│ Folheto │ Folheto │ Folheto │
│    4    │    5    │    6    │
│         │         │         │
└──────────────────────────────────┘

→ Imprime página 1 (frente)
→ Vira o papel
→ Imprime página 2 (verso)
→ Corta nos espaços
→ 6 folhetos prontos!
```
