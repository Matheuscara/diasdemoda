📄 Gerador de PDFs - Dias de Moda

Siga os passos abaixo para gerar os PDFs:

1️⃣ Folheto (6 por folha A4)

Vai abrir em uma nova aba. Depois:

  1. Aperte Ctrl + P
  2. Marque "Cores de fundo" ou "Gráficos de fundo"
  3. Destino: Salvar como PDF
  4. Salve como: folheto-6up.pdf

2️⃣ Cartão (frente e verso)

Vai abrir em uma nova aba. Depois:

  1. Aperte Ctrl + P
  2. Marque "Cores de fundo" ou "Gráficos de fundo"
  3. Destino: Salvar como PDF
  4. Salve como: cartao-duplex.pdf

⚠️ IMPORTANTE!

  • SEMPRE marque "Cores de fundo"
  • Margem: Nenhuma
  • Escala: 100%
  • Use Chrome ou Edge (Firefox pode dar problema)

✅ Checklist de Configuração

Quando abrir a janela de impressão, configure assim:

  • Destino: Salvar como PDF
  • Páginas: Todas
  • Layout: Retrato (folheto) / Paisagem (cartão)
  • Cores: Com cores
  • Margens: Nenhuma ou Mínimas
  • Opções: ✅ Cores de fundo
  • Escala: Padrão (100%)
