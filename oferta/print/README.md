## 🖨️ Como Imprimir

### Opção 1: Imprimir Diretamente (Recomendado)

**Para o FOLHETO (6 por folha):**
1. Abra `folheto-6up.html` no **Chrome** ou **Edge**
2. Aperte `Ctrl + P` (Windows) ou `Cmd + P` (Mac)
3. Configure:
   - ✅ **Cores de fundo:** ATIVADO (muito importante!)
   - Tamanho: A4
   - Orientação: Retrato (vertical)
   - Margem: Nenhuma
   - Escala: 100%
4. Imprima página 1 (FRENTE), vire o papel, imprima página 2 (VERSO)
5. Corte os 6 folhetos!

**Para o CARTÃO:**
1. Abra `cartao-duplex.html` no **Chrome** ou **Edge**
2. Aperte `Ctrl + P`
3. Configure:
   - ✅ **Cores de fundo:** ATIVADO
   - Tamanho: 85mm × 55mm (ou A4 e corte depois)
   - Orientação: Paisagem (horizontal)
   - Margem: Nenhuma
   - Escala: 100%
4. Imprima frente, vire, imprima verso

### Opção 2: Gerar PDF para Gráfica

1. Abra o arquivo `.html` no **Google Chrome** (ou Edge)
2. `Ctrl + P` (ou menu → Imprimir)
3. Destino: **Salvar como PDF**
4. **Configure igual acima** (cores de fundo ATIVADO!)
5. Salvar e levar para a gráfica

> Cada arquivo gera **2 páginas** (frente e verso). Peça impressão frente e verso na gráfica.

## Especificações para a gráfica

- **Folheto:** A5 (148×210mm), 4/4 (colorido frente e verso), papel couché 90–150g.
- **Cartão:** 85×55mm, 4/4, papel couché 250–300g, sem verniz necessário.
- **Sem sangria** (o layout já tem margem de segurança interna). Se a gráfica
  exigir sangria de 3mm, avise que o fundo pode ser estendido.
- Fontes: Cormorant Garamond (títulos) + Karla (texto) — embutidas no PDF.
